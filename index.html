Help & security

1. Secure reports: Use only Power BI secure embed URLs from Orient's tenant. Never use Publish to web for confidential business reports.

2. Permissions: Grant the display account access to each report and confirm its Power BI licensing. Row-level security still applies to the signed-in user.

3. Sign-in: Microsoft sign-in is handled by Power BI in the embedded frame. Browser privacy settings or third-party cookie restrictions may cause repeated sign-in prompts.

4. Local settings: The playlist and preferences are stored in this browser's local storage. They are not centrally managed and do not sync to another TV.

5. No secrets: This static frontend stores no password, client secret, refresh token or access token. Do not add credentials to this repository.

6. Access to this app: GitHub Pages access restrictions depend on Orient's GitHub plan and organization settings. If Pages cannot be restricted to authorized users on the chosen plan, do not assume the app itself is private; ask IT for an approved access-controlled hosting option. Power BI report permissions remain separate.

7. TV reliability: Test the chosen TV browser for Microsoft sign-in, session retention, fullscreen, iframe cookies, and scheduled rotation before putting the display into production.
